# 高画質ハイブリッドLP制作マニュアル

この手順に従うことで、画像のボケを防ぎ、ボタンを完璧な位置に配置できます。

## 1. 画像の準備（スライス）

1.  **デザインを分割する**:
    *   LP全体のデザインを、縦に10枚程度の画像（スライス）に分割してください。
    *   1枚の高さは、スマホで見た時に1〜2画面分くらい（1500px〜2000px程度）が目安です。
    *   **重要**: ボタンを重ねる予定の画像からは、あらかじめデザイン上のボタンを消しておいてください。

2.  **ファイル名の命名**:
    *   `slice_01.png`, `slice_02.png`, `slice_03.png` ... という名前で保存してください。

3.  **配置**:
    *   作成した画像を `html_LP_making/static/images/` フォルダに入れてください。

## 2. 企画書（JSON）の編集

`input/hybrid_v2_plan.json` を編集します。

*   `sections` 配列の中に、スライスした画像の数だけ項目を増やしてください。
*   ボタンを置きたい画像（セクション）には、`cta` オブジェクトを追加します。
*   `position_bottom`: 画像の下端からボタンまでの距離を `%` で指定します（例: `10%`）。

## 3. LPの生成

ターミナルで以下のコマンドを実行します。

```powershell
.\venv\Scripts\Activate.ps1
python generator.py input/hybrid_v2_plan.json
```

## 4. 微調整

1.  ブラウザで `output/index.html` を確認します。
2.  ボタンの位置がズレている場合は、JSONの `position_bottom` の数値を調整して再生成してください。
3.  画像がボケる場合は、さらに細かくスライス（分割）して1枚あたりのファイルサイズを抑えてください。
